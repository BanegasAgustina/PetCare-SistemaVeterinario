## Cambios que no se recomiendan ahora

- No eliminar ledgers/tablas de notificaciones push, refresh tokens o históricos en Layerbase sin plan de retención, backup probado y autorización de esquema.
- No cambiar JWT, OAuth, roles, permisos, SDK Expo ni mecanismos de pago para resolver hallazgos que no los involucren.
- No ejecutar migraciones desde este checkout; el responsable administra ese proceso externamente. Evitar invocar los scripts locales que requieren fuentes SQL no versionadas.
